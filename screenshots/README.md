# Assessment Screenshots

Add the final evidence screenshots to this folder using these names:

1. `01-git-github.png` — repository and successful `python hello.py` run.
2. `02-linux-sysinfo.png` — successful `scripts/sysinfo.sh` output.
3. `03-docker.png` — successful Docker build and container run.
4. `04-github-actions.png` — passing GitHub Actions workflow.
5. `05-nomad.png` — Nomad job status and/or allocation logs.
6. `06-loki.png` — Loki query showing the application log entry.

Keep screenshots readable and avoid exposing passwords, tokens, or other secrets.
